# WispKits (Paper 1.21.11 / Java 21)

A configurable Minecraft kit plugin with a GUI.

## Commands
- `/kit` — open kit GUI and click a kit to claim it
- `/kit claim <name>` or `/kit <name>` — claim a kit
- `/kit create <name>` — save your inventory as a kit (admin)
- `/kit edit <name>` then `/kit save <name>` — edit a kit (admin)
- `/kit icon <name>` — set the icon to your held item (admin)
- `/kit delete <name>` — delete a kit (admin)
- `/kit list` — list kits

## Build automatically
Open **Actions → Build WispKits → Run workflow**. After it finishes with a green check, open the run and download the `WispKits-jar` artifact. Unzip it and upload the `.jar` inside to your server's `plugins` folder, then restart.

Target: Paper 1.21.11, Java 21.
